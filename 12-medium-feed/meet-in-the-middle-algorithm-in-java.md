Image Source Brute-force search can run out of room long before the code itself gets hard to read. Meet-in-the-middle handles that pressure by cutting the input into two halves, finding the possible totals from each side, and then pairing those totals to reach the target. For subset sum, that changes the search from checking every possible full subset across 2^n choices into building two smaller collections near 2^(n / 2) in size.
